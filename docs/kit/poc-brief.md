# POC brief

**Who uses it:** SSE and Architect · time-boxed

Use the copy button on the block below. The editable master copy lives in the shared drive: *add link*.

```text
POC BRIEF  (maximum 3 days; never real client work)
Role: ________  Reviewer(s): ________

Question the POC must answer
  e.g. "Can event ordering per tenant be guaranteed with the chosen queue
  at 500 messages/second, and what does it cost?"

Constraints
  Technology to use or compare: ________
  Sandbox account or local only: ________
  Time box: ____ days. Stop when the question is answered.

Deliverables
  - Working spike in a repository
  - A 1–2 page findings note: what worked, what did not, limits,
    numbers measured, recommendation, what you would do next
  - 20-min demo + 40-min discussion

We assess
  Speed of learning · Quality of judgement under uncertainty ·
  Honesty about limits · Clarity of the recommendation
```
