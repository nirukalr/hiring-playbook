# Intern

Final-year students and recent graduates. We hire for potential: fundamentals, reasoning and how fast they learn.

**Candidate time:** about 3 hours · **Decision:** within 14 days · **Intake:** cohorts

## What we look for
- Solid fundamentals: data structures, OOP, SQL basics, HTTP
- Breaks an unfamiliar problem down and thinks aloud
- Has built something on their own and can explain it
- Takes hints well and learns visibly during the interview

**Must-haves:** problem solving and reasoning; learning and curiosity.

## Panel
One SE or SSE from the project, plus the project tech lead. HR for culture. No independent interviewer is needed; the Tech Leads' Forum calibrates intern scorecards each cohort.

## Stages
| Stage | Format | Time | Who |
| --- | --- | --- | --- |
| CV and academic screen | AI rubric tuned for projects, internships and grades; human review | – | TA |
| Online coding test | 2 auto-graded problems plus 10 fundamentals questions | 60 min | TA runs; TL sets pass mark |
| Technical interview | Project walk-through (15), fundamentals (10), live coding of a simple problem (20) | 45 min | SE/SSE + TL |
| Team meet | Informal session with the future buddy: how they learn, work together, ask for help | 30 min | Project buddy |
| HR culture interview | Values, motivation, expectations | 30 min | HR |

## Sample questions
- "Pick a project you are proud of. What was the hardest bug, and how did you find it?"
- "How would you store a student's course enrolments? What happens if a course is deleted?"
- "Count how many times the largest number appears in an array. What inputs would you test?"
- "What did you learn in the last month that nobody asked you to learn?"

## Red flags
- Cannot explain code in their own project
- Freezes rather than reasoning aloud, even with hints
- Copies an answer they cannot explain

!!! tip "Campus drives"
    Run the technical interview, team meet and culture interview as an assessment day for up to 30 candidates, with a group design exercise added.
